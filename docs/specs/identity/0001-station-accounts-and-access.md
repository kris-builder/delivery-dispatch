# 0001 网点与驿站员工账号及访问权限

Status: ready-for-agent

## 问题陈述

网点调度要组织直派和向下属驿站分拨。驿站站长要在自己的驿站收货、对账和安排上门服务。两类配送员都要登录领件，并只操作从所属单位授权给本人的包裹。

## 解决方案

员工用登录名和密码登录。每个账号有一种岗位及明确的所属单位。服务端按岗位和实际业务资源校验。网点与运力维护网点、下属驿站和两类配送员的档案，账号与身份负责登录、角色与账号状态。

## 用户故事

1. 作为网点调度，我希望发布本网点直派清单和下属驿站分拨单，以便安排上游作业。
2. 作为网点操作员，我希望确认本网点实际入站、发出和收回的包裹，以便查清实物交接。
3. 作为驿站站长，我希望确认本驿站实收、处理差异并安排本站配送员，以便管好自取和上门服务。
4. 作为网点或驿站配送员，我希望登录后只看到本人在所属单位的有效任务，以便正确领件。
5. 作为账号管理员，我希望在权限范围内开通、重置或停用员工账号，以便收回离岗人员的访问权限。

## 实现决定

| 岗位 | 账号归属与授权 |
| --- | --- |
| 网点调度 | 绑定一个派件网点。维护该网点的规则与网点运力，发布直派清单和发往下属驿站的分拨单，可核对本网点发出的批次。 |
| 网点操作员 | 绑定一个派件网点。操作本网点入库、备货、实际发出与返站收回。 |
| 网点配送员 | 绑定所属派件网点和本网点配送员档案。操作本人有效网点直派清单和实际持有的件。 |
| 网点转运司机 | 绑定所属派件网点和本网点 `TRANSFER_DRIVER` 人员档案。按人员档案 ID 校验本人受指派的分拨批次，审计使用员工账号 ID。可处理本人批次的现场差异及异常件回交，驿站站长执行驿站签收。 |
| 驿站分拣员 | 绑定一个下属驿站。办理本站已签收件的上架、备货和异常反馈。 |
| 驿站站长 | 绑定一个下属驿站。查看本驿站分拨单，办理实际收货、自取与返站，管理本驿站人员和上门任务。 |
| 驿站配送员 | 绑定所属驿站和本驿站配送员档案。操作本人有效的驿站上门清单，查询本人的计件记录。 |

- 演示初始化预置网点调度和各驿站站长。网点调度管理本网点操作员、网点配送员与网点转运司机账号，驿站站长管理本驿站分拣员与配送员账号。历史操作保留原账号及交接。
- 使用 Spring Security 同源服务端会话与 BCrypt。首登及重置密码后用临时密码进入修改流程，退出作废会话，空闲超时可配置。停用或重置后按账号状态与会话版本拒绝旧会话。修改请求校验 CSRF。日志记录账号操作人、目标和时间。
- 员工主体包括岗位、所属网点或驿站、上级网点及适用的配送员标识，均从服务端取得。请求里的单位、配送员或运单标识只定位目标。上级网点只能按职责查看分拨进度，实际收货、驿站派工及领取确认由驿站角色执行。
- 履约仍核对清单、实物保管和当前状态。收件人使用独立会话。 [收件人账号与登录](0002-recipient-accounts-and-access.md)

## 测试决定

从受保护的 HTTP 入口验收。用两个网点、同一网点下两个驿站及两类配送员区分权限。权限检查同时核对业务记录和操作人。

| 场景 | 可验收结果 |
| --- | --- |
| 调度发布本网点直派清单并向本网络驿站分拨 | 可查发布人和目标驿站。其他网点、其他驿站和普通配送员的越权操作被拒绝。 |
| 网点调度尝试代驿站收货或指定驿站配送员 | 请求被拒绝。驿站站长可以办理本驿站事务，不能代其他驿站办理。 |
| 网点配送员扫驿站上门件，或驿站配送员扫网点直派件 | 两种扫码均被拒绝，实物保管不变。 |
| 转运司机确认本人批次，并尝试替驿站签收或领取直派件 | 仅本人转运业务可执行，驿站签收与直派领件继续按对应岗位授权。 |
| 驿站分拣员依次处理本站已签收件、未签收件和其他驿站件，并尝试批签 | 仅本站已签收件可上架，保留操作员及货架记录。正式批签和领取核销由站长办理。 |
| 管理人员开户、重置或停用本单位配送员 | 绑定范围正确。首登先修改临时密码，重置或停用后旧访问失效，历史交接仍可查。 |
| 退出、超时、缺少有效 CSRF 或用收件人会话操作内部入口 | 受保护请求失败，业务数据保持原状。 |

## 范围之外

- 通用权限平台、跨单位兼职账号、总部账号体系和薪资结算权限。
- 实际分拨、驿站上门和计件的业务写入规则。

## 补充说明

第一批交付员工登录、首登改密、退出和会话约束，以及片区、在岗配送员查询接入员工会话。账号开通、重置、停用为第二批。发布、实物交接、驿站站内作业、司机指派及本人领件权限随各业务入口验收，版本与依赖见[路线图](../../ROADMAP.md#员工身份与业务入口验收)。

网点、驿站配送员共用配送工作台，网点操作员和驿站分拣员共用分拣工作台。任务范围由服务端会话、所属单位、有效授权与保管事实确定。 [工程规范](../../ENGINEERING.md#用户认证和权限设计) · [驿站交接](../pickup-station/0001-transfer-and-receiving.md) · [驿站上门与续派](../pickup-station/0002-home-delivery-service.md)
